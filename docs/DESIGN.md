# MyIdleRPG 設計文件（單人本地版）

參考作品：《TBH: 塔斯克巴·英雄》(Task Bar Hero)。一個常駐在螢幕底部、工作列高度的細長視窗，3 人小隊自動往右推進打怪、開寶箱、換裝、合成。本作為**單人離線版**：無伺服器、無市集/交易、無課金，存檔在本機。

## 0. 硬性限制

- 引擎：Godot 4.7，GDScript（全部加靜態型別），渲染器 GL Compatibility（已設定）。
- **美術只能用 Duelyst 素材（CC0）**。本 repo 是公開 GitHub repo，CraftPix / GandalfHardcore 素材授權禁止再散布，**一律不可複製進專案**。
  - 來源：`D:\Tools\Godot_v4.7.1\asset-pack\Game_Kits\Duelyst\duelyst_animated_sprites\`
  - 放置位置：`res://addons/duelyst_animated_sprites/`（資料夾名不可改，`.tres` 寫死此路徑）
  - **只複製用到的檔案**：每個單位/特效/圖示需同時複製 `spritesheets/<類>/X.png`、`X.png.import`、`spriteframes/<類>/X.tres`，保留相對路徑。並複製 `LICENSE`。
  - 用 `tools/import_duelyst.ps1` 依 `tools/duelyst_assets.txt` 清單複製，可重複執行。
  - 單位動畫名：`idle` / `breathing` / `run` / `attack` / `hit` / `death`，部分有 `projectile`、`cast*`。9 FPS。單位面朝右。
- UI 文字：繁體中文。

## 1. 視窗形式（TBH 核心特色）

- **工作列條模式（預設）**：無邊框、置頂、寬 = 主螢幕可用寬度，高 **180px**，貼齊螢幕可用區域底部（工作列上方）。畫面是一條橫向戰場 + 右側精簡 HUD（金幣、關卡、寶箱數、展開按鈕）。
- **展開模式**：視窗往上長高到 **620px**（底部仍貼齊），上方出現分頁面板：小隊 / 背包 / 技能 / 方塊 / 符文 / 關卡 / 設定。
- 可拖曳移動、可切換「置頂」與「條模式/一般視窗模式」，設定存檔。
- 設計解析度基準：戰場高 180px；單位縮放讓 100px 單格 ≈ 高 90px。

## 2. 核心迴圈

1. 小隊（1–3 名英雄）在戰場左側站位，背景捲動表示前進。
2. 怪物以**波次**從右側進場；清完一波進下一波。每關 **N 波（預設 5）+ 關卡首領**。
3. 擊殺得經驗、金幣，有機率掉**寶箱**。
4. 關卡首領必掉**藍箱**；打贏後解鎖下一關。
5. **全滅**：退回上一關並自動重試（不扣資源，只損失時間）。
6. 設定「自動推進」開/關：關閉時重複刷當前關。

## 3. 世界結構

- 難度：普通 → 噩夢 → 地獄 → 折磨（Phase 3 前只做普通）。
- 每難度 **3 幕**，每幕 **10 關**；第 10 關為**幕首領**，挑戰需消耗 1 顆**靈魂石**，打贏得幕首領箱並解鎖下一幕。
- 每關有**建議等級**；怪物等級 = 建議等級。難度倍率：普通 1×、噩夢 3×（等級 +30）、地獄 8×（+60）、折磨 20×（+80）。
- 怪物有元素屬性：物理 / 火 / 冰 / 電 / 混沌。噩夢起出現火焰、混沌重傷怪。

## 4. 英雄與職業

| 職業 | 定位 | 攻擊 | 主傷害 | Duelyst 建議單位 |
|---|---|---|---|---|
| 騎士 | 坦 | 近戰 | 物理 | `f1_general` |
| 牧師 | 坦補 | 近戰 | 物理/神聖(火) | `f1_altgeneral` |
| 遊俠 | 主輸出 | 遠程彈道、可穿透 | 物理 | `f1_ranged` |
| 法師 | 控場/AOE | 遠程法術 | 火/冰/電 | `f2_caster` |

（若建議單位動畫不合用，可換同陣營其他單位，並在 `data/classes` 更新。）

- 起始只有 1 名騎士；等級 5 解鎖第 2 位、等級 15 解鎖第 3 位（任選職業）。可隨時換陣，每職業獨立等級。
- 屬性：最大生命、攻擊力、攻速、暴擊率、暴擊傷害、防禦（減物傷）、四抗性（火/冰/電/混沌，上限 75%）、生命吸取、移速無意義不做。
- 升級：經驗曲線 `xp_to_next(L) = round(20 * L^2.88)`，等級上限 100。每級 +1 技能點，基礎屬性隨等級成長。下一關的進入等級為該關建議等級 +1；未達門檻時自動繼續刷目前關卡。
- 經驗懲罰：怪物等級比英雄低 10 級以上，經驗遞減。

### 技能（Phase 3）

每職業 4 個主動技能（裝備 2 個，自動施放、有冷卻）+ 4 個被動。技能點投入升級。例：
- 騎士：盾擊（暈眩）、嘲諷；被動：最大生命、傷害吸收。
- 牧師：治癒、力量祝福（隊伍增傷光環）、聖域、復活；被動：全元素抗性。
- 遊俠：穿透之箭（貫穿全排）、快速射擊（短時間爆發攻速）、多重射擊、迅捷覺醒；被動：暴擊、吸血。
- 法師：火球術、烈焰九頭蛇、閃電術（貫穿）、暴風雪（範圍緩速）；被動：冷卻縮減、範圍。

### 平衡基準

- 每個關卡固定 **5 波普通怪 + 1 個關卡首領**；第 10 關的同一首領才標記為幕首領。普通怪的池不包含首領，首領只在第五波清空後出現。
- 新關卡開始時存活英雄完全恢復；每清完一波，存活英雄恢復 **30% 最大生命**。死亡英雄不會被這個恢復拉回。
- 平衡基準（普通難度、Lv.1 騎士、無裝備／無技能）：生命 **380**、攻擊 **38**、防禦 **40**、攻速 **1.05**，目標是在 **90 秒內**清完 1-1。`core/battle_sim.gd` 是這條規則的無頭驗證模型。
- 一般怪的資料表 `balance.attack_multiplier = 0.35`；難度倍率主要放大生命、攻擊、防禦，攻速、暴擊率、暴擊傷害與生命吸取不隨難度倍率再次放大。
- 首領使用資料表中的壓力曲線：生命倍率 `0.72 + 0.016 × (Lv-1)`（上限 `1.15`），攻擊倍率 `0.65 + 0.012 × (Lv-1)`（上限 `1.10`），防禦倍率 `0.90`。因此同級別裝備隊伍應能過關，而低 5 級以上通常會在首領前／首領戰失敗。
- 平衡測試的普通關卡裝備是同等級的固定稀有裝置；噩夢測試使用同等級的史詩裝置與已裝備技能，代表進入噩夢時的最低合理隊伍配置。

## 5. 寶箱

- **白箱**：一般擊殺時，若白箱冷卻（預設 90 秒）已過，擊殺有機率（預設 25%）掉落；掉落後重置冷卻。
- **藍箱**：關卡首領必掉。**幕首領箱**：幕首領必掉。
- 寶箱進入**寶箱佇列**，有容量上限（預設 20）；滿了就不再掉白箱（藍箱/幕箱不受限）。
- 每種寶箱可設定「自動開啟」。開箱產出：裝備（1–3 件）、材料、金幣；藍箱/幕箱有機率出**靈魂石**（藍 2%、幕 8%）。
- 寶箱等級 = 掉落當下的怪物等級，決定裝備等級。

## 6. 裝備

- 欄位（7）：武器、頭盔、胸甲、手套、靴子、戒指、項鍊。
- 稀有度（顏色 / 隨機詞綴數 / 鑲嵌格）：

| 稀有度 | 顏色 | 詞綴 | 鑲嵌格（依序開啟） | 開箱權重 |
|---|---|---|---|---|
| 普通 | 白 | 0 | — | 60 |
| 優良 | 綠 | 1 | — | 25 |
| 稀有 | 藍 | 2 | 裝飾×1 | 10 |
| 史詩 | 紫 | 3 | 裝飾×2 | 3.5 |
| 不朽 | 紅 | 3 | 裝飾×2、雕刻×1 | 1.2 |
| 傳奇 | 橙 | 4 | 裝飾×2、雕刻×2 | 0.28 |
| 超凡 | 金 | 4 | 裝飾×2、雕刻×2、銘文×1 | 0.02 |

- 主屬性依欄位（武器=攻擊、防具=防禦/生命、飾品=抗性/暴擊），數值隨物品等級線性成長，稀有度倍率 1.0/1.1/1.25/1.45/1.7/2.0/2.4。
- 詞綴池：攻擊%、攻速%、暴擊率、暴擊傷害、最大生命、防禦、各元素抗性、生命吸取、金幣獲取%、經驗獲取%。
- 裝備限職業類型：武器分劍/杖/弓/法器，其餘通用。
- **背包**：預設 1 頁 40 格；符文可解鎖更多頁。滿了新裝備自動分解成金幣（可設定自動販售白/綠）。

## 7. 材料與鑲嵌（Phase 4）

- 三類槽：**裝飾**（寶石）、**雕刻**（符石）、**銘文**（卷軸）。材料也分稀有度，數值隨稀有度提高。
- 寶石：紅寶石=火抗、藍寶石=冰抗、黃玉=電抗、紫水晶=混沌抗、祖母綠=混沌抗+生命、鑽石=全抗。
- 符石（雕刻）：攻擊%、攻速%、暴擊等攻擊向。
- 卷軸（銘文）：稀有，大幅加成或特殊效果（技能等級 +1）。
- 鑲嵌可**無損拆除**。

## 8. 方塊（合成，Phase 4）

- 放入 **3 件同稀有度裝備** → 產出 1 件新裝備：等級 = min(方塊等級, 投入平均等級+5)，稀有度有 15% 機率升一階（至寶以上 3%）。
- 方塊有等級與經驗，合成取得經驗（投入等級越接近方塊等級經驗越多；高出方塊等級 10 以上經驗減半）。
- 材料也能 3 合 1 升階。

## 9. 符文（永久升級，Phase 4）

用金幣購買，不可重置。節點與每級效果：
- 金幣獲取 +10%、經驗獲取 +10%、白箱掉落率 +10%、首領箱品質 +5%、全隊攻擊 +3%、全隊生命 +3%、全抗 +1%、背包頁 +1（最多 5）、寶箱容量 +5。
- 價格：`base * 1.6^level`。

## 10. 離線收益（Phase 4）

- 啟動時計算離線時間（上限 12 小時）。以當前關卡的「每分鐘擊殺數 × 獎勵」估算經驗與金幣（效率 50%），並依白箱冷卻補發寶箱（受容量上限）。啟動時彈窗顯示結算。

## 11. 存檔

- `user://save.json`，含版本號欄位以便遷移。每 30 秒自動存、關閉視窗時存。
- 存：英雄、裝備、背包、寶箱佇列、材料、金幣、靈魂石、關卡進度、方塊、符文、設定、最後存檔時間。

### Phase 4 實作基準

- 材料包以材料 id 堆疊，不占用裝備格；寶石／符石／卷軸的 socket type 分別為裝飾／雕刻／銘文。捲軸白箱掉落率 1%、藍箱 5%、幕箱 15%。
- 方塊輸出等級為 `min(方塊等級, 三件裝備平均等級 + 5)`；一般稀有度升階機率 15%，傳奇以上 3%。方塊下一級經驗為 `round(20 + 方塊等級 × 10)`，投入平均等級高出方塊 10 級以上時，該次方塊經驗減半。
- 符文價格為 `base × 1.6^level`；本次採用的 base 依序為金幣 100、經驗 120、白箱 180、首領箱品質 260、隊伍攻擊 300、隊伍生命 300、全抗 420、背包頁 500、寶箱容量 360。符文不能退款。
- 離線結算使用 `battle_sim` 估算目前關卡清除速率；最多計算 12 小時、效率 50%，白箱以 90 秒冷卻補發並受目前寶箱容量限制。系統時鐘倒退時不發收益。

## 12. 架構

```
res://
  addons/duelyst_animated_sprites/   # 只含用到的 CC0 素材
  autoload/        # GameState(存檔資料), SaveManager, EventBus(signal hub), WindowManager
  data/            # 純資料：classes/, monsters/, stages/, items/, skills/, runes/（.tres 自訂 Resource 或 .gd 常數表）
  core/            # 純邏輯、不依賴節點：stats.gd, combat_math.gd, loot.gd, item_gen.gd, progression.gd, offline.gd
  scenes/
    main.tscn      # 入口：戰場 + HUD + 展開面板
    battle/        # battlefield.tscn, unit.tscn, projectile.tscn, damage_number.tscn
    ui/            # 各分頁面板
  tests/           # 無頭測試
  tools/           # import_duelyst.ps1, duelyst_assets.txt
```

- **邏輯與表現分離**：數值計算、掉落、合成、升級都在 `core/` 的純函式/RefCounted 類別，方便無頭測試；節點只負責顯示與呼叫。
- 隨機數：集中用一個可設定種子的 `RandomNumberGenerator`，測試時固定種子。
- 以 `EventBus` signal 串接戰鬥事件（unit_killed, chest_dropped, level_up, stage_cleared…）。
